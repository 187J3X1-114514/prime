# 离线光传输契约

外部“离线渲染模式”由独立的 `OfflineRenderer` 实现。它和 `RealtimeRenderer` 平级组合
`TraceBackend`、场景、材质、光源与 Vulkan 提交工具，不共享 set 1、wavefront 状态、输出
图像、调度或顶层传输策略。

## 会话与资源

`OfflineSession` 在进入时冻结世界、resident scene、相机姿态、天文、灯光、材质、相机介质、
atlas handle、纹理 revision、动态纹理列表、传输设置，以及进入前实时显示通道的 16-byte
自动曝光状态。世界或资源变化会退出；纵横比变化只重建投影与离线尺寸资源并从 0 样本
重新累积。离线预览不重新测光；最终曝光仍可实时调整，AgX HSV 使用内部默认参数，自动测光
自动曝光强度只在恢复实时渲染后影响新的测光目标。

实时与离线 pipeline/SBT 可同时驻留，但分辨率相关资源严格互斥。进入离线前等待已有 GPU
工作完成并销毁实时输出、重建历史、raw signal 和 96-byte×2 wavefront；退出时同步销毁
离线运行均值、显示资源和 144-byte×1 wavefront。共享场景、TLAS/BLAS、atlas 与大气保留。
曝光复制采用两阶段切换：请求帧仍由实时渲染器提交复制，完成回调只标记快照 ready；后续
帧确认完成后才销毁实时尺寸资源并创建离线资源，录制中的命令不会引用已退休缓冲。

## Wavefront ABI 与调度

离线路径记录为单槽每像素 144 bytes：80 bytes 物理传输及两层介质栈、16 bytes 辐亮度与
首命中距离、16 bytes 首命中反照率与材质 flags、32 bytes 完整 f32 deferred Area 请求。
物理传输的 `throughput.w` 以 f32 保存 eta scale；Area 控制位保存生成请求时的介质栈深，
退出事件把散射前栈顶消光保留在散射后已失活的介质槽中。两者都不增加记录尺寸。
另有两条单槽索引队列。4K backing 为 1,260,748,832 bytes，即约 1202.34 MiB，不创建实时
stable radiance、raw frame、PSR 或反射/透射双路图像。

调度固定为：

```text
head → 8 × (step → area) → tail → resolve
```

head 与稀疏 tail 内联 Area shadow；常规 step 只保存 f32 方向、距离与贡献，独立 area stage
追踪阴影并回写。running mean 使用 RGBA32F，alpha 与 RGB 使用同一样本数累计修正后的测光
亮度；当前离线显示使用冻结曝光，因此 alpha 仅保留测光统计语义，不驱动预览。

## 透明与介质

每个透明界面从 RoboCute 完整反射+透射闭包随机选择一个事件，sample PDF 包含事件选择概率，
因此每像素始终只有一条离线路径。反射保留介质栈；透射按闭包结果入栈或出栈并传递 relative
eta；实体玻璃与水的颜色由介质栈按实际段长应用 Beer-Lambert 吸收，不再逐界面乘玻璃
表面滤色；TIR 只产生反射。粗糙透明参与完整双侧
sample/eval/PDF 与 NEE，平滑 delta 透明跳过 NEE。受保护的
`shaders/bsdf/core/robocute_*.slang` 生产可达核心不包含这些产品适配，也未被修改。

Vanilla 染色玻璃以 alpha 0.4 固定标定体积吸收，当前 texel alpha `<= 0.5` 选择光滑界面、
`> 0.5` 选择粗糙界面。普通玻璃主体为无色光滑介质，alpha `> 0.5` 的边框改为不透明粗糙
漫反射表面。粗糙度优先读取 LabPBR，否则读取“默认粗糙度”设置；alpha 不缩放粗糙度。
“无缝玻璃”默认开启：普通玻璃边框按无色光滑主体处理，染色玻璃的粗糙分类被禁用；体积
颜色、alpha 0.4 吸收标定及介质栈行为均不改变。关闭后恢复纹理装饰分区。

NEE 阴影不求解透明界面的 Snell 折射。它保持原始表面到光源的直线连接，并通过透明实体的
有向边界距离矩稳定累计该线段上的 RGB 光学厚度；起点介质不预乘远端光源距离，因此短介质
段不会从两个巨大浮点数相减得到。薄壁界面按 1/16 米名义厚度累计。因而这是明确的直线
吸收近似，不是镜面折射链连接。

## 直接光与 MIS

每个合格非 delta 顶点分别采一次太阳和一次两级灯光树 Area 光。若前一顶点存在 Area NEE
技术，BSDF 续接命中面积光时重建完整反向树 PDF 并使用 power heuristic；前一顶点为 delta
或没有该技术时权重为 1。太阳保持独立 NEE/MIS；行星地平线测试在太阳 shadow ray 前用
实际圆盘采样方向精确拒绝零贡献样本。最大反弹数为 128，所有散射统一计入 bounce，并从
第二次散射开始 Russian roulette。透射事件把 `relativeEta²` 累积到 eta scale，存活率为
`min(sqrt(max(throughput) × etaScale), 1)`，存活路径按概率重加权。
