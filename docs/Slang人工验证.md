# Slang 迁移人工验证

迁移代理不启动游戏、不操作窗口或屏幕。下列验证只能由用户执行；在对应 pipeline 自动门禁通过后，
迁移代理会补充可复现步骤、预期结果和需要回传的数据。未到相应阶段的项目保持“待设置”。

| 阶段 | 人工验证 | 需要回传 | 状态 |
|---|---|---|---|
| 独立 compute/post | 自动曝光、最终显示、数值调试与太阳阴影层级对照 | 截图、异常描述、必要时 trace | 自动门禁通过；待用户验证 |
| 命中/材质/BSDF | 材质、透明、介质边界、完全封闭环境和极端场景 | 截图、场景条件、异常首次出现阶段 | 自动性质/分布/能量门禁通过；待用户验证 |
| wavefront realtime | 小窗口、最大化、反复调整分辨率并持续运行至少 10 分钟 | 是否崩溃、驱动恢复、trace 与帧时 | 自动 ABI/队列门禁通过；待用户验证 |
| wavefront offline | 离线收敛与迁移前参考画面对照 | 图像、采样数、误差观察 | 自动编译/ABI 门禁通过；待用户验证 |
| 最终切换 | 使用主线存档与资源包回归，并采集 realtime GPU trace | GPU trace、帧时、寄存器和视觉结论 | 当前迁移阻碍；等待用户操作 |

## 最终 A/B/A 门禁

迁移前基线固定为 `e4316353d2c5970af3dcd215e021c1dbd3a9c5e9`。基线与当前工作树必须使用
同一存档、资源包、配置、相机、时间/天气、输出分辨率和缩放模式；关闭 HUD 或使用完全相同的
裁剪矩形。不要复用另一实现生成的 temporal history。

每个代表场景分别捕获：

1. 基线清空 history、预热到稳定后连续两帧 `B0/B1`；
2. Slang 版本清空 history、以同样预热条件捕获连续两帧 `S0/S1`；
3. offline 使用相同采样数；realtime 记录相同稳定区间的平均、P95 和最大帧时；
4. 至少包含普通室外、完全封闭无光、发光材质、玻璃/水介质边界和先前泛红复现场景。

对 tone-mapped RGB（排除 HUD）计算基线噪声 `RMSE(B0,B1)`，Slang 误差取四个 `B/S` 组合
RMSE 的中位数。迁移图像门禁为：

- Slang RMSE 不超过 `max(1.25 × 基线噪声, 2/255)`；
- 每个 RGB 通道的有符号均值偏差绝对值不超过 `2/255`；
- 数值诊断中没有 NaN、±Inf 或首次异常阶段像素；
- 不出现可复现的几何缺失、材质分类变化、介质栈/透明边界错误、无光自发红或曝光漂移；
- realtime 平均与 P95 帧时相对基线不得回退超过 5%，且最大化/反复缩放持续十分钟无崩溃或
  驱动恢复。若帧时差异超过门限，同时提交同区域 GPU trace，按执行模式定位后再判定。

回传 `B0/B1/S0/S1` 原始 PNG、场景/采样条件和帧时即可；迁移代理只离线读取这些文件，
不启动游戏或操作屏幕。
