# 着色器等价性能优化报告

## 范围

本轮只修改 GPU/shader 路径，覆盖参考累积、实时积分、NRD 前后处理和 DLSS Ray Reconstruction 准备。没有修改生产 Java/CPU 路径，没有修改受保护的 `robocute_bsdf_*.glsl` 参考移植，也没有实施改变采样方差或引入实时偏差的方案。

允许的差异仅为数学等价重排；非边界输入由现有 GPU 属性测试验证。可能改变方差或引入偏差的候选方案单独记录在《着色器性能优化-未实施的方差与偏差方案》。

## 主要改动

### 参考累积

- 增加只返回总辐射和首表面距离的参考积分路径。
- 参考路径继续使用相同的 BSDF、MIS、介质栈、俄罗斯轮盘赌和透明首界面固定双分支。
- 不再为参考累积构造三套降噪 guide、反射信号分区或 8 层 PSR delta 链。
- 透明固定分支增加无 guide 的适配入口；属性测试逐字段比较它与实时入口的方向、响应、PDF、相对折射率、事件和介质栈。

### 实时积分

- 太阳、星图和面积光按顺序求值，避免全部 Sobol 样本及多个光照分解结构同时存活。
- 可降噪表面的能量 guide 与 BSDF 采样共享一次 RoboCute 状态初始化。
- 同一直接光样本的可见性判断和 BSDF 求值复用着色法线；透明求值复用外向法线。
- 缓存 guide 所需的粗糙度和法线，避免 LabPBR 解码及法线解包在同一表面重复执行。
- 数值诊断关闭时，在分类前退出，不再在正常显示模式执行 NaN、Inf、范围和方向分类。

### NRD

- 将 raygen 到 `nrd_motion.comp` 的私有 scratch 契约作为单一验证边界；前处理不再重复消毒已经有限且限幅的 albedo、hit distance、方向和 packed normal。
- 增加经过消毒数据的 demodulate、双信号联合限幅、hit-distance 归一化和打包入口，并用稳健入口逐 bit 对照。
- 运动矩阵计算与辐射 demodulate 重排为不重叠的值生命周期。
- 天空和无效反射 guide 提前退出；SH1 两个方向都为空时跳过四邻域深度、法线读取和 re-jitter。
- 合成阶段只在反射 guide 有效时读取反射 specular material 与反射 SH 数据。

### DLSS Ray Reconstruction

- 天空走独立短路径，不读取表面位置、法线、noisy diffuse/specular 或太阳信号。
- 表面颜色在运动矩阵投影前完成并写出，避免多个辐射向量跨两次投影保持存活。
- 消除 raygen 已经保证的重复有限性、范围和 FP16 限幅检查。
- primary 与虚拟反射 motion 仍保留矩阵结果的有限性检查，因为矩阵和 GPU 投影属于外部边界。

`rr_prepare` 的静态 load 略增来自天空与表面分支显式化；运行时天空分支不再读取五个表面输入图像。

`world.rgen.spv` 从 441,064 字节增至 457,932 字节，约增加 3.8%。原因是同一预编译模块同时保留专用参考积分和实时积分，以满足游戏内快速切换而不临时编译。调试 SPIR-V 的函数局部代理如下：

| 函数 | 指令 | 局部变量 | load | store | call |
|---|---:|---:|---:|---:|---:|
| 参考续接积分 | 356 | 63 | 61 | 70 | 28 |
| 参考首表面/透明分支 | 687 | 133 | 126 | 150 | 53 |
| 实时主积分 | 1,727 | 230 | 313 | 327 | 82 |
| 实时透明续接 | 1,141 | 160 | 205 | 204 | 52 |

这说明参考调用路径已经与实时 guide/PSR 大状态隔离，但不能替代 Nsight 或驱动 pipeline executable 统计。最终寄存器数、occupancy、spill、显存带宽和帧时仍需在目标 RTX 4090 上测量。

## 验证

- `verifyRoboCutePort` 通过，受保护参考文件未改动。
- 发布 shader 与 SER permutation 均通过 `glslangValidator` 和 `spirv-val`。
- GPU 属性测试覆盖稳健/可信 NRD 入口逐 bit 一致、透明固定分支逐字段一致，以及既有 BSDF、材质、传输、LUT 和分布性质。
- `gradlew check shaderTest` 全部通过。

## 目测与性能验收重点

1. 分别测试参考累积、NRD 和 DLSS RR，不只测试默认实时路径。
2. 覆盖天空、普通不透明表面、玻璃、水面、水下、透明掠射角和多层透明。
3. 检查太阳反射拖影、透明后首表面稳定性、相机平移/旋转及静止收敛。
4. 记录 raygen、`nrd_motion`、`nrd_composite` 和 `rr_prepare` 的 GPU 时间。
5. 用 Nsight 对比寄存器数、occupancy、local-memory spill、图像 load/store 和分支效率。
6. 若参考路径的驱动首次编译时间明显增加，优先评估独立预编译 pipeline；不要回退为游戏内按需编译。
