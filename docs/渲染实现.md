# 渲染实现

本文记录 Prime 当前渲染器的稳定技术边界。历史调查、待办和实验方案分别放在调查报告、
`TODO.md`、`FIXME.md` 和未实施方案文档中。

## 渲染模式

### 实时路径追踪

实时模式每像素每帧通常生成一个 Prime 材质模型样本。支持的 RTX 设备优先使用 DLSS Ray
Reconstruction；不可用或初始化失败时回退到 NRD-FSR。禁用后处理时以原生分辨率直接
显示 noisy color，不运行降噪或超分。

五档重建质量统一控制内部渲染尺寸。模式或尺寸变化会整体重建相关资源并重置不兼容的
时间历史。

### 离线累积截图

外部仍称截图模式；内部由独立的 `OfflineRenderer` 执行。会话冻结相机、太阳、地形、
灯光、材质、atlas/纹理 revision、相机介质和动态纹理列表，在窗口原生分辨率累积线性
RGBA32F 运行均值。它旁路实时降噪、超分和调试覆盖层，不钳制高亮样本。
显示预览直接对当前运行均值测光并立即收敛，不模拟实时曝光适应；最终曝光度只重新调度
显示变换，不修改运行均值或样本数。

离线使用自己的随机透明闭包与全路径直接光估计，不再累积实时透明双分支产品模型。
其传输契约见[离线光传输契约](离线光传输契约.md)。

窗口纵横比变化会保留冻结的相机姿态、更新投影并重新累积；世界或资源切换会安全退出，
避免混合不同场景。

## 主积分器

- Vulkan KHR ray tracing pipeline，管线递归深度为 1；
- 实时与离线分别编译 pipeline、SBT、set 1 ABI 和 wavefront 状态，不存在运行时模式分支；
- 实时为 `head → 12 × step → tail → resolve`，共 15 次 RT dispatch；
- 离线为 `head → 12 × (step → area) → tail → resolve`，共 27 次 RT dispatch；
- miss、closest-hit 和 any-hit 只返回遍历结果，不承担积分器状态机；
- 支持且真正提供 reorder 模式的设备可以使用
  `VK_EXT_ray_tracing_invocation_reorder`；
- 128 次反弹是异常长路径的安全上限，不是正常路径目标。

实时 Russian roulette 在至少一次保证续接后开始。首透明面的折射支与所有后续透明顶点都按
纯 delta 处理：不执行 NEE，也不增加 RR 深度。首透明面的粗糙反射仍按有限反射瓣执行
NEE/MIS 并正常计数。太阳和方块面光源使用下一事件估计与 power-heuristic MIS。

`PathState`、`SurfaceInteraction`、BSDF、PDF、光源样本和采样维度是积分器契约。
wavefront 只保存状态并调度，不重新解释光传输数学。

## 透明与介质

本节以下内容只描述 `RealtimeRenderer` 的低方差重建模型。离线不会继承这些分叉与确定性
透射限制。

透明采用确定性 trick 是实时架构决策：多界面折射链无法由普通 NEE 阴影射线正确连接，
按 Fresnel 随机切换反射/折射会让 denoiser guide 在不相容的几何历史间跳变，而为完整
折射链引入 MNEE、双向连接或专用 guiding/reservoir 的迭代、光线、状态与显存成本超出
当前预算。详细推导和输出契约见[透明渲染与实时重建](透明渲染与实时重建.md)。

只有相机主射线的首个可见表面为透明接口时，积分器才固定生成折射和条件反射两条路径。
折射方向由几何法线与界面 IOR 确定，响应为玻璃表面因子或水的白色因子乘 `1-F`；反射支保留
RoboCute 的镜面/GGX 条件反射，响应已经包含 `F`。两支都被求值，因此 PDF 不再包含分支
选择概率。主射线先命中不透明面后才遇到的透明面，以及分叉后的所有透明命中，都只返回
确定性折射 delta 样本，不再随机选择反射或乘 Fresnel；达到临界角时回退到唯一有效的
全反射事件。

玻璃是表面滤色材质。为近似原版直接在 sRGB 编码域执行的 alpha 混色，每次穿面使用
`square(mix(白, sqrt(linear Rec.2020 基础色), alpha))`。这是 gamma 2 的便宜近似，
比线性混合更浓；厚玻璃通常滤色两次。玻璃不进入介质栈，也不按段执行 Beer–Lambert
吸收。水面为白色折射面，只更新介质栈；水中每段仍使用实测吸收系数。树叶薄壁透射使用
独立闭包，不属于该玻璃语义。

阴影射线使用 RGB 透射率、带符号水段累计量和真实遮挡距离。玻璃候选命中逐面滤色后继续
遍历；水边界以剩余距离差累计水中长度并在末端钳制；只有不透明面或通过 alpha 测试的
cutout 才产生标量遮挡和 SIGMA penumbra 距离。透明滤光预乘到太阳或面光源 radiance，
不伪装成标量 visibility。阴影路径忽略透明界面的折射，始终沿原 NEE 线段遍历。

介质栈固定保存两个非空气体积，现在只由水使用。水边界仍要求法线正确并遵循可解释的
进出顺序；相机初始介质只特殊识别水。原版流体 tessellation 的首个 quad 绕序定义
authored outward normal；为光栅背面剔除追加的严格反向副本在 cluster 翻译中折叠。
浅水或斜面不得用面中心相对方块中心的位置推断朝向，因为有效顶面可以整体低于半格；
岩浆 area emitter 与水介质进出共享该法线契约。

## 实时重建

### DLSS Ray Reconstruction

Prime 向 DLSS RR 提供 noisy color、主 motion、反射 motion、linear depth、
normal/roughness 和 diffuse/specular albedo。透明主路径被组织为透射主表面与独立反射
运动，不提交语义不真实的 Color Before Transparency 或 specular hit distance。RR 是完整
实时后端；启用时不调度 NRD 或 FSR。

### NRD-FSR

NRD 使用主历史和透明反射历史处理普通表面、透明透射替代表面及反射支；太阳直射可通过
同一 NRD instance 的 SIGMA 过滤。去噪后的线性 HDR 结果交给 FidelityFX FSR 3.1.4
Upscaler。

运动向量采用 NRD 的非抖动 2.5D 屏幕空间约定：

```text
old = new + MV
```

XY 指向上一帧 UV，Z 是上一帧与当前帧 view-Z 之差。天空运动只包含相机旋转。FSR 复用
XY，并单独接收 reversed-infinite depth。

实时样本、NRD、FSR 和 DLSS 的历史都只在 GPU 提交成功后推进。图像首次布局状态以及
星图、BSDF LUT 等一次性上传同样在提交成功后发布；仅录制或被拒绝的命令缓冲不会污染
下一帧。世界、渲染原点、模式和不兼容尺寸变化会显式 reset。

每个最终显示通道独占一组 GPU 自动曝光直方图与状态。它按清零、直方图、曝光更新、显示
变换的顺序记录并以 Vulkan 屏障连接，不回读 CPU；相机切换或重建 reset 时直接收敛到
当前测光目标。

透明首接口分叉、确定性续接、直线 NEE 滤光、PSR guide、双路 NRD、透明相位恢复、FSR
输入以及 DLSS RR 透明分组的完整约定见[透明渲染与实时重建](透明渲染与实时重建.md)。

## 材质

没有 PBR 数据时，不透明材质使用方块纹理与 biome tint，默认感知粗糙度为 0.90、介电
F0 为 0.04、IOR 为 1.5。显式材质数据优先。

LabPBR 1.3 当前使用：

- 感知光滑度与线性粗糙度；
- 介电 F0；
- 预定义和自定义金属；
- 次表面散射权重；
- 发光强度。

切线空间法线会读取并重建，但当前着色仍使用几何法线。AO、高度和孔隙率仅保留语义，
尚未接入遮蔽、位移或天气系统。辅助图集跟随原版 atlas 的 mip、padding、动画帧顺序和
插值进度；资源重载会原子替换图集并重建受影响 Section。

## 光照、颜色与显示

积分器、材质、光源、路径吞吐和截图累积统一使用 D65 白点的线性 Rec.2020。Minecraft
纹理和 tint 在材质边界从 sRGB 解码并转换。

光源包括光谱大气、太阳、内嵌 Gaia 星空和从原版发光等级及纹理估计的方块面光源。星图
全天求值并经过大气透射；地面白天由天空与大气亮度自然掩盖，白天外太空仍可轻微看到。
太阳与星图共享同一天文帧：Minecraft 日角作为当地真太阳时角，观察纬度和固定太阳黄经
通过 23.43928° 地轴倾角计算太阳赤纬、太阳赤经与当地恒星时。世界东、西、南、北分别为
`+X`、`-X`、`+Z`、`-Z`；默认北纬 30°、春分，因此正午太阳位于正南方且高度为 60°。
星图只在路径逃逸时求值，不参与 NEE。发光材质进入两级灯光树，所有可执行 NEE 的反弹
都使用同一套灯光树采样与反向 MIS PDF；太阳保持独立 NEE。实时仅在 primary guide
表面执行一次灯光树 NEE，后续只采太阳；离线则在每个合格非 delta 顶点各采一次太阳与
一次灯光树，并在 BSDF 命中面积光时重建完整反向树 PDF。level-15 方块光基准为
`1.5`，星图基准辐亮度比例为 `0.075`，对应的用户 EV 都是相对偏移。

### 世界空间太阳体积阴影

aerial perspective 的局部太阳可见性来自 RT 构建的世界空间方向光深度 clipmap。它与
CSM 使用相同的分级覆盖思想，但不栅格化太阳视图：每个 texel 从太阳侧沿反方向追踪 TLAS，
保存首个不透明命中的光空间深度。追踪复用生产阴影 hit group，因此 alpha cutout 仍执行
纹理测试，玻璃和水仍按直线 NEE 的透明语义继续遍历。

每个方向 bank 包含五张 `512×512 R32F` 图像，texel 尺度依次为
`0.5/1/2/4/8 m`，以相机在固定太阳正交基上的投影为中心，半径依次覆盖
`128/256/512/1024/2048 m`。图像按世界 texel 坐标环形寻址；相机平移只追踪新露出的条带，
相机旋转不改变缓存坐标或内容。场景流式更新把实际发生替换或驱逐的 4×4×4 Section
cluster 包围盒投影到每级缓存：当前可读 bank 在新 TLAS 发布后同帧直接重追踪合并后的
受影响光柱，不向 aerial LUT 暴露中间未知值；非活动 bank 才把区域归并到 tile dirty mask，
按现有预算渐进修复。渲染原点变化或漏掉增量 revision 时执行完整重建。

两个 bank 保留旧太阳方向并渐进构建新方向，避免太阳旋转时直接破坏当前可读缓存。实时
初建或完整 reset 的第一帧先覆盖接触相机的四个 `128×128` tile，五级共 `327,680` 条
射线，随后每帧追踪一个 tile、再用 12 帧完成；已有可读 bank 时，换向仍保持每帧五级
各一个 tile，即 `81,920` 条射线并在 16 帧完成。相机滚动只增加新条带；可读 bank 的
地形变更按相接矩形合并后精确重追踪，非活动 bank 仍只增加受影响 tile。十张深度图合计
`10 MiB`。截图在开始累积前一次完成当前方向的五级缓存，共 `1,310,720` 条射线，后续
样本读取不再变化。

aerial LUT 在 3×3 邻域取最大遮挡深度；初建、完整重建或非活动 bank 中尚未完成的 texel
使用 `+∞`，只能暂时减少阳光，不能重新制造洞穴漏光。当前两个 `RGBA16F` aerial 体积均为
`64×36×128`，距离上限为 `2.048 km`，深度采用平方分布。每个 `64×36` 方向 cell 对应一个
128 线程 workgroup；每个线程只以两个中点样本积分相邻深度中心之间的局部段，再按
`(La, Ta) ∘ (Lb, Tb) = (La + Ta·Lb, Ta·Tb)` 做共享内存 inclusive scan，得到从相机到全部
128 个深度中心的累计辐亮度与透射率。太阳可见性在两个光谱组之间共享，不再让每个输出
voxel、每个光谱组各自从相机重新 march。

在 16:9 的 4K 输出上，一个方向 cell 约覆盖 `60×60` 像素。约 `100 m`、`1 km` 和最远层的
相邻深度中心间距分别约为 `7.1 m`、`22.4 m` 和 `31.8 m`；两个段内样本把对应的最大步距
再减半。与旧 `32³ × 16 steps × 2 groups` 路径相比，每次重建的局部太阳可见性查询从
`1,048,576` 次降为 `589,824` 次，光谱介质步从 `1,048,576` 次增为 `1,179,648` 次，另有
七轮共享内存 scan；两张体积的显存从 `0.5 MiB` 增至 `4.5 MiB`。因此主要精度提升不是用
九倍完整重积分换来的，代价集中在共享内存累计、更多输出写入和 `4 MiB` 常驻显存。

局部可见性同时调制单次太阳散射和当前大气 multiple-scattering 近似，但不调制纯视线透射。

这是明确的太阳单方向有限模型，不是任意方向天空可见性、参与介质多次散射或局部灯光
体积阴影的无偏解。3×3 保守查询会在远级扩大遮挡，透明材质也不会产生彩色体积阴影。
后续扩展局部灯光时不能直接把方向光深度比较套到点光或面光，必须另行定义缓存参数化和
可见性误差边界。

Noisy、NRD-FSR 和 DLSS RR 都在生成最终全分辨率线性 HDR 后进入统一显示边界。自动曝光
使用 DRT 输入域的 Oklab `L³` 测光：非负 Rec.2020 先按显示边界转换到 BT.709 并裁掉
负通道，再取 Oklab lightness 的三次方。`L³` 保持线性曝光尺度，输入增加 `1 EV` 时测光
也增加 `1 EV`；它面向 DRT 显示观感，不表示物理 luminance。有效介电与植被表面先按
18% 参考反照率完全除去 albedo 影响，不再混入原始亮度；albedo 测光最低按 `0.02` 处理，
避免修正项在接近黑色时数值发散。纯白表面的测光倍率为 `0.18`，相对原始亮度可提高
约 `2.47 EV` 曝光。该修正不改实际 HDR 辐亮度，也不按粗糙度排除光滑高光，高亮像素
仍由直方图最高 1% 裁剪处理。金属、透射界面、天空和无效 guide 保持原始亮度测光。

修正后的全部有效像素统计到 256 档 `[-16, +20] EV` 对数直方图，裁掉最低和最高各 1%
后计算几何平均，并按 Reinhard 原始自动 key 公式保留高调与低调构图。设保留范围的最低、
最高和平均对数亮度分别为 `l`、`h`、`m`，则 `q = (2m - l - h) / (h - l)`，场景 key
倍率为 `4^q`，等价于在目标曝光上增加 `2q EV`。为避免近乎均匀画面把几个直方图档的
噪声放大成曝光震荡，分母实际使用 `max(h - l, 2 EV)`；动态范围达到 `2 EV` 后与原公式
完全一致，只有一个亮度档时偏移为 `0 EV`。目标中灰为 `0.16`，基准曝光偏移为 `0 EV`。
自动曝光只允许在暗场补偿，最终自动 EV 限制为 `[0, +4]`，不会因太阳或其他强高光进入
视野而压暗整个画面。
进入强光的 T90 为 0.5 秒，进入暗处为 2 秒。
无有效像素时保持上一实时状态；尚未初始化、reset 或截图即时模式遇到无有效像素时使用
`0 EV`。实时后端复用当前帧 albedo 与材质类别 guide；截图把每个路径样本的修正测光
亮度累计在 RGBA32F 均值图的 alpha 通道，保持与 RGB 样本数一致且不增加独立历史。

最终显示倍率为：

```text
PRIME_DISPLAY_EXPOSURE × 2^自动曝光EV × 2^最终曝光度EV
```

其中 `PRIME_DISPLAY_EXPOSURE` 为 `1.0`，最终曝光度默认为 `0 EV`、范围 `[-8, +8] EV`、
步进 `0.25 EV`。倍率应用后再通过 Oklab DRT 映射到 sRGB Rec.709；高光过曝量默认
`1.0`，即不启用额外过曝。自动曝光、最终曝光和 DRT 都不写回线性历史，最终曝光也不
触发场景或截图累积重置。

物理着色点与 Vulkan 遍历偏移原点分离。路径坐标相对于 Prime 渲染原点，避免使用大尺度
绝对世界 `float` 坐标。

## 场景与资源

`render/terrain` 负责 Section 快照、异步网格化、virtual cluster、BLAS 驻留和 TLAS
替换。Minecraft/Fabric 捕获边界只发布实际接受的不可变 quad 事实；同一个 4×4×4
Section virtual cluster 的 64 个固定槽位全部捕获完成后，`ClusterSceneTranslator`
一次性完成 layer 分类、流体表示转换、普通三角化、宏面/纹理体素建模、OMM、灯光和
primitive ABI 打包。相同显式捕获值、资源 epoch 和设置产生相同 CPU 输出；局部 builder
与 scratch 不逃逸该调用。

每个 virtual cluster 仍以一个原子 generation 替换，并对应一个世界灯光树叶。普通地形
保持一个 base BLAS/TLAS instance；启用实验性纹理体素表面时，复用的细节 mesh 拥有额外
BLAS，范围内每个适用方块面增加一个 TLAS instance。关闭实验功能时仍是单 BLAS/instance
路径。草方块侧面的静态基础层/染色覆盖层在开启细节时烘焙为一个体素材质 mesh；关闭细节时
编码为一个 macro raster-composite primitive，由材质层按精确 atlas 像素偏移选择 base 或
overlay，不创建额外 TLAS instance。

同平面反向 cutout quad 若材质映射完全相同，会折叠成一张双面 sheet；若像向日葵花盘一样
分别使用正面和背面纹理，则保留两个 primitive 并标记为 authored-front-only。world/shadow
any-hit 在 alpha 测试前拒绝错误一侧，OMM 对这类 primitive 固定为 unknown，避免确定
microtriangle 绕过正反面裁决。

CPU mesh 可以使用多个有界 segment，最终上传仍生成单个 BLAS。资源不足时不会提交不完整
generation，也不会静默丢弃几何。大型 primitive 数组由构建器把所有权移交给编译结果，
后续只读借用并零拷贝上传；不会为形式不可变复制完整地形。

`TraceBackend` 独占共享 set 0、BSDF LUT、星图和公共提交资源；`RealtimeRenderer` 与
`OfflineRenderer` 是平级组合者，各自独占 pipeline/SBT、set 1、wavefront、调度与输出。
实时 pipeline 启动创建，离线 pipeline 首次进入时懒创建并保留。模式切换先等待已提交 GPU
工作，再同步释放非活动侧全部分辨率相关资源；共享场景、BLAS/TLAS、atlas 与大气不重建。

`render/vulkan` 拥有 Vulkan handle、VMA 分配、同步、SBT、pipeline 和加速结构。资源采用
prepare/commit：下一驻留映射和 TLAS 描述先完整构造，命令被提交系统接受后再原子发布，
旧 BLAS/TLAS 和 staging 页按 Vulkan timeline 延迟销毁；渲染热路径不调用
`vkDeviceWaitIdle`。

Java/GLSL ABI、工作色彩空间和关键常量由 `shaders/abi.json` 统一声明并在构建时生成和
验证。

更一般的模块、状态和副作用规则见[纯函数式架构](纯函数式架构.md)。

## 诊断与重放

视频设置提供 NRD、FSR、DLSS RR、三角面分布和数值异常视图。数值异常诊断区分 NaN、
正负无穷、有限负值、非法方向、样本拒绝、单位范围及 FP16 上限。
NRD/FSR 数值诊断冻结自动曝光并绕过最终曝光；RR 的 HDR 对比区域使用当前曝光，数值型
诊断区域保持原始数值，避免显示倍率改变诊断含义。

`Ctrl+Alt+F10` 使用两套隔离历史运行 64×64 生产 wavefront 和 NRD 输入路径，检查语义并
比较同平台逐 bit 输出。通过的捕获保存在 `run/prime/replay/last-success.prseq`，默认不
进入版本库。

详细测试边界见[着色器属性测试与数值诊断架构](着色器属性测试与数值诊断架构.md)。
