# 着色器属性测试与数值诊断架构

## 目标与边界

这套测试验证实际编译并在 Vulkan 设备上执行的 Slang 行为。Java 负责构造确定性输入、
批量提交和缩小失败见证，不复制待测公式。本地 RoboCute Slang 参考移植已删除；紧凑
OpenPBR 通过参考导出的性质、分布、能量和状态测试验收，不编译第二套实现。

生产数学按关注点拆分：

- `shaders/core/numerical.slang`：无状态数值分类与诊断阶段/字段编号。
- `shaders/core/transport_math.slang`：吞吐量乘除、MIS、面积到立体角 PDF、Beer-Lambert 和轮盘赌。
- `shaders/material/labpbr.slang`、`shaders/material/material_translation.slang`：整数材质传输格式与物理参数翻译。
- `shaders/core/nrd_common.slang`：NRD 编码、距离、辐射限幅、反调制和无效值边界。
- `shaders/bsdf/compact`：生产 OpenPBR ABI、专用状态与数学实现。
- `shaders/bsdf/adapter/bsdf.slang`：Prime 公开 BSDF/介质栈适配。

这样可以分别审查数值稳定性、材质语义、采样契约和降噪 ABI，也允许以后只替换某一
算法模块及其属性套件。

## 执行数据流

`ShaderPropertyBatch` 先令每个 case 只写一个失败掩码。失败时，它按固定 seed 和原始输入
重放最多八类不同的 `(kind, mask)`，再请求完整 witness。常规批量不承担大输出带宽，
失败仍能定位到输入位模式和中间结果。

`ShaderComputeRunner` 是独立的 Vulkan 1.2 compute 所有者。绑定 0/1 固定为输入/输出
SSBO；额外资源通过显式绑定加入，支持 2D/3D sampled image、2D storage image、
push constants 和 XYZ workgroup。它不依赖 Minecraft 客户端或渲染器状态。

## 当前覆盖矩阵

| 关注点 | 生产入口 | 主要性质 |
|---|---|---|
| OpenPBR 基础与闭包 | `shaders/bsdf/compact` | 恒等式、事件、半球、PDF、状态、分布、能量与 LUT |
| Prime 公开 BSDF | `shaders/bsdf/adapter/bsdf.slang` | 拒绝/净化前的原始异常、无效样本规范化、有效载荷 finite/nonnegative、方向、η、介质栈 |
| 积分器与灯光数学 | `shaders/core/transport_math.slang` | 溢出安全乘除、MIS 互补/尺度不变、衰减组合、轮盘赌重加权 |
| 材质 | `shaders/material/labpbr.slang`、`shaders/material/material_translation.slang` | 16-bit 轴域、字节端点、缺省值、金属 ID、Fresnel 单位区间 |
| NRD | `shaders/core/nrd_common.slang` | NaN/Inf 清除、FP16 上限、颜色往返、法线、距离、反调制、合并限幅 |
| 测试执行器 | `ShaderComputeRunner` | sampled→storage→SSBO、push constants、二维 dispatch |

## 运行时诊断

数值异常诊断图的 RGBA 分别存储：

1. 累积数值标志；
2. 首次异常阶段；
3. 首次异常的 path bounce；
4. 首次异常字段类别。

“数值异常”模式按 NaN、正无穷、负无穷和有限越界着色；“异常首发阶段”和“异常首发字段”
分别按首次异常的阶段和字段类别着色。BSDF adapter 通过显式
`PrimeNumericalObservation` 在拒绝样本或钳制 denoise albedo 之前观察原始值，并由调用它的
integrator 立即提交到当前 path 的 `PrimeNumericalDiagnostics`；不使用 shader 全局可变状态。
关闭原始诊断时 observer 使用禁用哨兵并只执行可预测的早退。参考库将 event 标为 NONE 时
payload 未承诺初始化，Prime 不读取这种被放弃的载荷，避免制造假阳性。

## 回归命令

`PrimeBsdfDiagnosticsGpuTest` 以原始 IEEE-754 NaN/Inf、负响应、非法方向和禁用 observer
验证上述拒绝边界。`gradlew test` 运行 CPU/ABI 测试；`gradlew shaderTest` 强制需要 Vulkan
compute 并运行全部 GPU 属性测试。CI 安装 Mesa Lavapipe 后执行两者，因此没有物理 GPU
也不能静默跳过着色器行为回归。
