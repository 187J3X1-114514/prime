# 区块簇场景翻译架构

Prime 以对齐的 `4×4×4` Section cluster 为地形替换单位。流送不依赖原版可见 Section、遮挡图
或原版 raster 编译队列；这些只代表栅格呈现，不能完整覆盖光追可见性和间接照明。

## 数据流与所有权

```text
Minecraft 模型、atlas、region
  ↓ VanillaSectionCapture / VanillaSpriteResolver（资源 epoch lease 内）
CapturedSectionGeometry + CapturedSprite
  ↓ CapturedCluster
ClusterSceneTranslator（纯 CPU 翻译）
  ↓ CpuClusterMesh / CompiledCluster
TerrainStreamer（desired/current、调度与上传）
  ↓
render.vulkan.terrain.TerrainScene（staging、BLAS/TLAS、resident scene）
```

- `render.scene.vanilla` 是唯一观察 Minecraft 模型、`TextureAtlasSprite`、Mixin accessor 和
  `NativeImage` 的适配边界；
- `render.terrain` 只处理 Prime 值、CPU mesh、OMM、发光分布、light tree 和翻译算法；
- `render.runtime.terrain.TerrainStreamer` 单一拥有请求、generation、in-flight、取消与重排；
- `render.vulkan.terrain` 单一拥有 GPU staging、resident cluster、BLAS/TLAS 和 compaction。

## Sprite 捕获契约

`VanillaSpriteResolver` 在每个 cluster 内用 `IdentityHashMap` 去重原版 sprite，并转换为：

- `SpriteId(namespace, path)`：稳定资源身份；
- `CapturedSprite`：atlas UV、帧尺寸、动画事实和唯一帧序列；
- `SpritePixelView`：可选的只读 ARGB 像素借用。

`CapturedSprite.equals/hashCode` 只比较稳定身份、布局和帧事实，不比较原版对象身份或像素
adapter 身份。像素视图可以零拷贝借用 `NativeImage`，因此只允许在创建它的资源 generation
lease 内读取，禁止跨 cluster 或跨线程缓存。

像素不可用是显式数据状态：OMM 使用 unknown-opaque，发光重要性退化为 uniform，纹理体素
面保留标准 quad。非预期的布局、算术和编程错误仍 fail-fast，不作为 reload 降级吞掉。

## Reload 与异步任务

`ResourceEpochCoordinator` 以单调 generation 隔离 Minecraft 外部资源：

1. render 线程在 snapshot dispatch 前取得短 lease；
2. worker 排队期间不持有 lease，避免共享 executor 上的 reload 死锁；
3. worker 开始后重新获取同一 generation，并在 Section 编译、cluster 翻译和像素读取期间持有；
4. generation 已 retired 时返回显式 `CANCELLED`，不访问旧资源；
5. 完成队列使用 `SUCCESS`、`CANCELLED`、`FAILURE`，取消会释放 in-flight，并在 cluster 仍
   desired/current 时重排；失败保持 fail-fast。

reload 先 retire 当前 epoch，异步等待最后一个 reader 退出，再跨过 Minecraft preparation
barrier；apply 安装新 epoch 并使场景失效。异常和取消通过幂等 abort 重新开放资源，且 ticket
只影响创建它的 renderer。

## 原子替换与版本

一个 cluster 的 64 个 Section 一次捕获和翻译，普通几何作为一个逻辑替换提交。上传成功前
旧 resident cluster 继续可用；替换被 host 接受后才发布新 revision 并退休旧 GPU 资源。

desired window、dirty generation 和 worker result 必须匹配。过期结果可以释放，但不得覆盖
更新的 cluster。世界切换、视距变化、资源 reload 和 voxel 设置变更都通过 generation 或
全场景 invalidation 收敛，不通过隐式共享对象状态传播。

## 几何与材质边界

- block、fluid 和 Fabric quad 都在 vanilla 边界转换为 `CapturedSectionGeometry.Surface`；
- 面合并仅在稳定 sprite、材质、朝向、UV 和双面语义相容时发生；
- LabPBR 在资源边界映射 `Identifier ↔ SpriteId`，纯 terrain 不依赖 Minecraft identifier；
- normal alpha 高度只驱动可选纹理体素 relief；关闭或缺少像素时沿用标准 quad；
- 动态方块实体与实体走动态场景路径，不并入持久 terrain cluster。

## 维护门禁

修改捕获或翻译链时至少验证：

- stable sprite equality、动画帧与自定义 namespace/path；
- OMM、发光分布、双面折叠、merge 与体素采样；
- missing pixel fallback 和 lease 释放后不再访问像素；
- 取消释放 in-flight、过期结果不发布、失败仍 fail-fast；
- `verifyArchitecture` 中纯 terrain 不依赖 Minecraft texture/model、Mixin 或 Vulkan。
