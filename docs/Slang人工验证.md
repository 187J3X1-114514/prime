最终 Slang 构建正常呈现并通过运行与性能回归，因此不再存在阻止语言迁移结束的人工项。离线
A/B/A 方法仍保留为未来工具链、浮点模式或大规模 Shader 架构升级的复验模板。

## 后续重大 Shader 变更的 A/B/A 门禁

历史迁移前基线为 `e4316353d2c5970af3dcd215e021c1dbd3a9c5e9`。需要复查迁移本身时可继续
使用它；普通后续优化应另选变更前提交作为 A/B/A 基线。两侧必须使用
同一存档、资源包、配置、相机、时间/天气、输出分辨率和缩放模式；关闭 HUD 或使用完全相同的
裁剪矩形。不要复用另一实现生成的 temporal history。

每个代表场景分别捕获：

1. 基线清空 history、预热到稳定后连续两帧 `B0/B1`；
2. Slang 版本清空 history、以同样预热条件捕获连续两帧 `S0/S1`；
3. offline 使用相同采样数；realtime 记录相同稳定区间的平均、P95 和最大帧时；
4. 至少包含普通室外、完全封闭无光、发光材质、玻璃/水介质边界和先前泛红复现场景。

对 tone-mapped RGB（排除 HUD）计算基线噪声 `RMSE(B0,B1)`，Slang 误差取四个 `B/S` 组合
RMSE 的中位数。迁移图像门禁为：

- Slang RMSE 不超过 `max(1.25 × 基线噪声, 2/255)`；
- 每个 RGB 通道的有符号均值偏差绝对值不超过 `2/255`；
- 专用 GPU 数值属性测试没有 NaN、±Inf、负值或非法方向失败；
- 不出现可复现的几何缺失、材质分类变化、介质栈/透明边界错误、无光自发红或曝光漂移；
- realtime 平均与 P95 帧时相对基线不得回退超过 5%，且最大化/反复缩放持续十分钟无崩溃或
  驱动恢复。若帧时差异超过门限，同时提交同区域 GPU trace，按执行模式定位后再判定。

回传 `B0/B1/S0/S1` 原始 PNG、场景/采样条件和帧时即可；迁移代理只离线读取这些文件，
不启动游戏或操作屏幕。
