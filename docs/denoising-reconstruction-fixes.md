# 降噪与时间重建修复说明

## 材质解调制必须使用真实 lobe 能量

REBLUR 接收的是去材质后的 illumination。输入和输出必须满足同一对称关系：

```text
illumination = radiance / guide
reconstructed_radiance = filtered_illumination * guide
```

旧实现使用一套通用材质因子重新估算 diffuse/specular guide。这套估算无法准确表达当前完整 BSDF 闭包，尤其不能覆盖金属、薄壁、透射和 delta 链上的方向能量。结果是输入除以一种材质含义，输出却乘回另一种材质含义，容易偏色并错误放大掠射角高光。

当前实现直接从实际初始化后的 BSDF 状态计算 diffuse/specular 方向能量，并把它们作为 REBLUR 解调制和重调制的唯一 guide。guide 为零的通道保持零，使用条件除法，不再制造 `0.001` 的假材质下限。

## 黑点的数值来源

有限的 BSDF、PDF 和路径吞吐相乘后仍可能溢出为 `Inf`，介质衰减、俄罗斯轮盘补偿和多个贡献求和也可能产生非有限值。旧流程在较晚阶段才检查结果，并可能把已经积累的整个 lobe 清零，因此单个异常样本会表现为随机黑点。

现在在以下边界分别验证完整结果：

- BSDF sample 的 PDF、方向和权重。
- 路径吞吐乘积。
- 介质衰减后的吞吐。
- 俄罗斯轮盘补偿后的吞吐。
- 每次辐射贡献及其与累计值相加后的候选结果。

实时路径会隔离异常贡献并保留此前有效的辐射，避免数值失败扩散到降噪输入；参考累积则将该条完整路径标记为无效，不把部分路径计入均值。PDF 的最低值仍保持为 `1e-4`，用于控制极低概率高权重样本的方差；该规则没有被移除。
