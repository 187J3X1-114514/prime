# 着色器性能优化候选台账

## 目的与边界

本文记录会改变采样方差、重建估计、显示测光或实时偏差的着色器性能方案，以及已经落地、
明确关闭或需要等待新证据的相关决策。数学等价的局部改写只在它来自实测热路径、决定后续
架构边界或已经被实机证伪时保留结论。

状态含义：

- **1.0 前**：发布前仍应完成的验收或清理，不包含新的渲染算法；
- **1.0 后有条件**：不是发布阻塞项，只有满足文中观测门槛后才进入独立实验；
- **后备回滚**：当前基线出现不可接受回归时恢复已知正确实现，不代表主动优化方向；
- **已落地**：当前产品路径已经采用；
- **已关闭**：当前目标下不采用，重新开启必须先说明瓶颈或产品目标变化。

历史成本数据只约束 `RealtimeRenderer`。`OfflineRenderer` 使用独立 pipeline、单槽 wavefront、
全路径 Area NEE 和随机完整透明闭包；实时简化、有偏方案和临时诊断模式不得渗入离线累积。

自动曝光位于全分辨率线性 HDR 之后，不改变路径估计器的期望或方差，但会改变误差的显示
可见度。当前把完整测光补偿钳制到 `[-16, +16] EV` 后在对数域应用一半，最终范围为
`[-8, +8] EV`；暗场中的噪声、firefly 和固定漏光最多会在显示端被放大 256 倍，因此验收
不能只观察 `0 EV` 白天场景。

## 1.0 发布结论

当前没有值得在 1.0 前继续实施的着色器估计器、wavefront 调度或 ABI 性能改造。实时激进
直接光基线、实时/离线双渲染器、太阳地平线拒绝和离线 eta-aware RR 已经分别完成实现与
实机验收。继续改动的潜在收益要么缺少瓶颈证据，要么会重新改变已经接受的方差、透明重建
或发布资源契约。

1.0 前只保留一项工作：

1. **固化当前发布基线。** 完成本文末尾的发布矩阵，记录三类场景、城市昼夜、水面、快速
   转身、灯光突变、离线累积和峰值显存结果；这属于验收，不再调整估计器。

太阳体积阴影的洞穴、远景与区块流送验收已经完成，洞穴视距雾漏光关闭；临时
cost-isolation 入口及其产品选项也已经删除。两项均不再列入发布待办。

除当前正确性阻塞项和水/玻璃材质基线外，本文记录的可选强化全部跳过，不再延长 1.0 发布
周期。发布矩阵只用于发现回归和固化当前基线，不作为重新开启候选算法的默认理由。

如果发布矩阵发现当前次级面积光方差不可接受，1.0 前的安全处理是恢复已经验证过的完整
次级 Area NEE，而不是临时设计随机稀疏、reservoir 或新的 MIS。任何新的折中进入 1.0 后
实验，不在发布窗口内边实现边确定画质基线。

## 当前产品基线

### 实时与离线独立积分器

状态：**已落地**

- 实时执行 `head → 12 × step → tail → resolve`，共 15 次 RT dispatch，使用 96-byte×2
  路径记录和实时重建输出。
- 离线执行 `head → 12 × (step → area) → tail → resolve`，共 27 次 RT dispatch，使用
  144-byte×1 路径记录、完整 f32 deferred Area 请求和运行均值。
- 两侧独占 set 1、pipeline/SBT、wavefront 和尺寸资源。候选必须明确属于哪一侧，不能因为
  共享底层算法而重新引入运行时模式分支或跨渲染器可变缓存。

### 实时主表面 Area、次级仅太阳

状态：**已落地并接受为 1.0 基线**

2026-08-02 城市固定视角的四个 cost-isolation 抓帧为：

| 模式 | 帧时间 | 相对旧基线 | 含义 |
|---|---:|---:|---|
| 旧完整基线 | 51.01 ms | — | 主、次级均执行完整直接光 |
| 无首透明反射续接 | 42.01 ms | -9.00 ms | 固定反射分支的成本上界 |
| 无次级 Area NEE | 35.34 ms | -15.67 ms | 次级灯光树和 Area shadow 的成本上界 |
| 两者均无 | 31.13 ms | -19.88 ms | 两项存在占用率与调度重叠，不能线性相加 |

隔离模式来自改造前的完整估计器，只表示成本上界。当前正式实现已经补齐正确权重并删除不再
需要的实时 Area 阶段：

- primary guide 表面固定采样一次太阳和一次方块面光；
- 后续非 delta 顶点只执行太阳 NEE，面积光仍可由 BSDF 续接命中；
- 深层命中面积光时前一顶点没有竞争 Area 技术，因此 MIS 权重为 1；
- step 与 tail 使用相同策略，不会在调度边界切换估计器；
- 实时由 27 次 RT dispatch 降为 15 次，离线仍保留全路径 Area NEE。

该方案没有删除面积光能量；相对当前有限路径模型，它只删除了次级 NEE proposal，保留
BSDF-hit estimator，因此改变方差而不改变期望。

实机验收观察到夜晚灯光阴影略暗、闪烁更明显，但暗场总体权衡可接受。该结果已经作为产品
画质基线接受；除非发布矩阵出现新的可复现回归，不恢复次级 Area NEE，也不继续在这一项上
搜索更细的随机稀疏档。

### 完整次级 Area NEE 恢复

状态：**后备回滚**

- 只在发布矩阵证明当前暗场方差或降噪伪影不可接受时启用。
- 恢复的是拆分前已验证的每个合格次级非 delta 顶点完整灯光树采样、Area shadow 和反向
  MIS，不在发布窗口内叠加 Bernoulli 稀疏或新的请求压缩。
- 该回滚会恢复已知显存、dispatch 和 GPU 成本；它是画质安全阀，不是 1.0 性能候选。

### 主表面灯光树与反向 MIS

状态：**已落地**

- primary guide 表面从两级灯光树选择一个面积光；粗糙透明首面直接承担该角色，纯 delta
  透明链则由链后的 primary replacement 承担，二者不会重复采样。
- 前向采样和发光面命中的反向查询读取相同 f32 节点记录。普通采样不读取反向专用 parent
  元数据。
- 面积光位置、选择概率和面积到立体角转换进入完整 PDF。只有实际存在竞争 Area NEE 的
  前一顶点才执行 power-heuristic MIS。

### 实时透明与俄罗斯轮盘赌边界

状态：**已落地并接受为 1.0 基线**

- 首个可见透明接口固定生成 `(1-F)` 折射支和包含 `F` 的条件反射支；后续透明接口使用
  现有确定性透射/TIR 语义。该固定双路径模型服务 NRD/RR guide 稳定性。
- 实时非 delta 路径至少保证一次续接，此后以最大 throughput 计算存活率并限制在
  `[0.05, 0.95]`，存活路径按相同概率重加权。
- 纯 delta 透明接口没有 NEE 顶点，不增加 RR 深度。固定最大反弹数仍是模型截断。
- 离线不继承该透明模型：每个透明接口从完整闭包随机选择一个事件，并使用独立的
  eta-aware RR。

### 太阳地平线拒绝与离线 eta-aware RR

状态：**已落地**

- 实时与离线使用太阳圆盘实际采样方向，在 shadow trace 前执行与大气远距透射相同的精确
  行星相交测试。落到行星后的样本原本贡献为零，因此拒绝不改变估计器；收益集中在夜晚和
  日出日落附近。
- 离线路径在 144-byte 记录原有的 `throughput.w` 中累积透射 `relativeEta²`。存活率为
  `min(sqrt(max(throughput) × etaScale), 1)`，反射保持尺度，成对折射率互相抵消；路径仍按
  存活概率重加权。
- 实时 RR 与透明豁免保持不变，不承担离线算法成本。

### 星图与完整天空直接光

状态：**已关闭**

- 星图只在续接射线逃逸时求值，不生成 shadow ray，也没有参与 MIS 的星图 PDF。旧 alias
  table、方向采样和 NEE 已删除。
- 当前大气只通过世界空间太阳深度 clipmap 提供局部太阳可见性，不等价于完整天空或参与
  介质多次散射。补齐完整物理模型属于 1.0 后画质功能，不是当前实现的免费优化。

## 已关闭的性能尝试

### PDF-only 与零质量变化的热路径窄化批次

状态：**已关闭**

- 批次曾包含 composition PDF 窄化、deferred 请求窄加载、LabPBR 字段窄解码、局部 BSDF
  state 复用、面积光距离复用和若干结构字段删除；还试验过 metalness endpoint 分支、alias
  命中窄读取和 eligibility 控制流重排。
- 保守子集曾缩小生产 SPIR-V，但 live register 数量没有变化。整批抓帧先回归，移除新增
  分支后仍只有测量噪声内收益，已经全部回滚。
- SPIR-V 大小不再作为收益代理。没有新的独立瓶颈证据时，不重新实施同类局部改写。

### 实时 Area 请求压缩与 shadow-ray RR

状态：**已关闭**

- 实时次级 Area NEE、独立 Area raygen、请求打包和 shadow 回写已经删除，请求压缩与
  “低贡献 Area shadow-ray RR”均没有实施对象。
- 离线 f32 Area 请求属于 144-byte 单槽 ABI，不是恢复实时请求队列的现成实现，也不需要
  为实时峰值显存让步。
- 若未来重新引入实时次级 Area NEE，应按新的 ABI、请求率和显存预算重新设计；旧
  `psrPacked` 空位、fp16 请求和 4K 双槽索引估算不再是当前契约。

### 移除 LabPBR normal ray payload

状态：**已关闭到 normal-map 合同重启**

- tangent normal、AO 和 height 尚未应用到 BSDF 或 temporal geometry，但 packed normal
  仍是完整 LabPBR 材质传输的一部分；当前明确等待 normal filtering、切线连续性和 NRD
  world-normal guide 一起接入。
- 删除单个 `uint` 不会缩小当前 64-byte `TracePayload` 的对齐后尺寸，只可能改变一个标量的
  live state；类似字段窄化没有改变生产 shader 的 register 档位。
- 该改动需要同时修改 raygen、closest-hit、miss、生成 ABI 和属性测试，收益未经证明而
  回归面较大。1.0 前保留字段；将来实现 normal-map 合同时统一重审 payload，而不是先删后加。

### 随机选择首透明分支或直接光家族

状态：**已关闭**

- 按 Fresnel 概率只选择首面反射或折射会令 realtime guide 在不相容的替代表面、深度、运动
  和方向间跳变，不作为普通性能候选。
- primary 太阳样本还负责 SIGMA 的未遮挡照明、visibility 和 penumbra，不与 Area 随机二选一。
- 次级直接光已经固定为仅太阳；重新随机选择太阳/Area 属于新的估计器，而不是当前基线的
  局部优化。

## 1.0 后有条件候选

下表只保留具有明确重启门槛的候选，不表示实施顺序。

| 候选 | 重启门槛 | 当前判断 |
|---|---|---|
| Wavefront step/tail 边界 | 取得每轮双队列长度和 tail 迭代分布，证明固定 12 轮不是合理交点 | 可能省调度/队列流量，也可能放大发散；1.0 前不盲调 |
| 材质或路径类别拆队列 | shader 指标证明 BSDF 分支而非 traversal/内存是主要发散源 | 当前已有 SER path-class hint；纯金属/非金属拆分的队列成本可能更高 |
| 首透明反射续接 RR | 发布后仍确认固定反射支是主要 GPU 成本，并可单独验收水面与玻璃闪烁 | 完全删除上界约 9 ms，但无偏 RR 会增加高能反射稀疏方差 |
| 纯 delta 透明链 RR | 长玻璃链在真实内容中形成可复现尾部成本 | 不扩大 slot，但会产生累乘权重和玻璃幕墙闪点 |
| 灯光树方向/BSDF 评分 | 灯光树节点访问或零贡献选择率成为可测瓶颈 | 有潜在方差收益；前向与反向 selection PDF 必须使用同一精确规则 |
| LightNode 压缩 | 灯光树常驻显存或带宽在整帧/峰值中占比显著 | 当前节点量相对 wavefront、纹理和 AS 较小，解码与支持集风险不值发布期承担 |
| 实时非 delta RR 调整 | 普通间接续接而非透明、shadow 或 traversal 成为主要成本 | 当前策略已经激进；继续提前会增加暗场稀疏方差 |
| 时空样本序列 | 有固定 replay 和降噪后时域指标，可独立比较 Sobol/蓝噪声方案 | 可能改善闪烁，但会改变 NRD/RR 历史和自动曝光抖动，必须单独验收 |
| 自动曝光采样预算 | 暗场误差成为发布后主要画质问题，并允许有界动态帧时 | 容易形成噪声—测光反馈；不进入离线累积 |
| 分层或稀疏直方图 | profiler 证明自动曝光 histogram 是整帧显著成本 | 会改变小高光、洞口和纯黑区域的测光时间稳定性 |
| reservoir/ReGIR | 恢复多反弹 Area/GI，或灯光树采样重新成为主要成本 | 当前实时只有 primary Area NEE，新增历史、显存和失效系统没有对应收益 |

### Wavefront step 与 tail 边界

- 减少 step 次数会更早进入线程发散较强的 tail；增加次数则提高调度和队列流量。
- 重新评估前必须记录每轮 source/destination queue 长度、tail 实际迭代数和不同分辨率曲线。
- 调整必须保持反弹上限、RR、NEE 和路径权重，验收覆盖城市透明长链、水面和森林高遮挡。

### 材质或路径类别拆队列

- 新队列会增加存储、原子、dispatch 和稀疏阶段空置。当前 trace 已按 path class 和实例类别
  提供 SER coherence hint，LabPBR metalness 也已翻译为明确分量。
- 若重启，只针对透明、体积或其他有显著成本差异的类别使用短生命周期分类；不得仅根据
  单个 shader coherence 判断收益，也不得为未启用类别增加持久显存。

### 透明续接 RR

- 首透明反射只允许对已经生成的 reflection continuation 独立 RR，不能在反射/折射间随机
  切换 primary guide 所有者。
- 一个保守实验可以从 `q=max(0.5, sqrt(max(throughput)))` 开始；存活支按 `q` 重加权。该
  参数只记录研究边界，不是预定产品值。
- 纯 delta 链可用 `bounce - rrDepth` 得到接口数，无需扩大 slot。任何实验都必须统计路径
  权重尾部，而不只比较平均反弹数。

### 灯光树评分与节点表示

- 当前评分使用节点功率和到 AABB 的距离平方。发光面朝向锥、立体角上界、BSDF 粗糙度或
  着色法线可能减少零贡献选择。
- 着色点相关评分必须由前向 sample 与反向 emissive-hit PDF 完整复现；不能只改前向遍历。
- 节点量化必须保持所有非零光源的非零支持，bounds 保守向外扩张，前向和反向读取相同解码值。

### 时空样本序列

- Sobol 维度编排、分支 seed、蓝噪声置换和跨帧相位通常不改变单样本期望，但会改变误差
  频谱、denoiser history、测光抖动和灯光阴影闪烁。
- 只允许作为单独画质算法实验；静止截图均值或 shader 时间不能证明其产品收益。

### reservoir 与世界空间缓存

- 当前精确两级灯光树只在实时 primary guide 表面采样一次 Area；在这个基线上引入 per-pixel
  或世界空间 reservoir，没有足够工作量可摊销其状态、原子、失效和显存成本。
- 如果以后重启，缓存必须由实时渲染器独占，使用带 generation 的稳定 light handle，始终
  重新追踪 visibility，并在世界、cluster、灯光纹理或能量变化时有明确失效边界。
- 离线继续使用精确灯光树和完整反向 PDF，不复用实时历史。

## 仅实时允许的有偏实验

以下方案均为 **1.0 后有条件**，不得进入离线参考累积：

| 方案 | 可能收益 | 主要风险 |
|---|---|---|
| 辐射或吞吐量钳制 | 抑制 firefly 与历史污染 | 压低 HDR 尾部，自动曝光后形成系统性暗偏 |
| 粗糙度下限或高光瓣展宽 | 降低尖锐高光方差 | 改变材质外观；水、玻璃和镜面需要独立边界 |
| 固定路径深度或低吞吐量强制终止 | 直接限制最坏成本 | 丢失间接光和深层透射，暗场最多被放大 256 倍 |
| 降噪 guide/history 近似 | 降低重建成本或提高响应 | 改变最终时域估计，可能产生拖影、边界残差和曝光闪烁 |

任何钳制阈值必须定义在曝光前线性 Rec.2020，并提供被删除能量诊断；不能让自动曝光反馈
决定当前阈值。任何 guide/history 改动必须同时检查静止收敛、相机运动、薄透明边界、反射
太阳、遮挡显露和灯光突变。

## 统一验收要求

### 1.0 发布矩阵

发布验收至少覆盖：

1. 沙漠、森林、城市三类固定 replay，记录中位数/P95 GPU 帧时、寄存器/占用率、RTCore、
   L2/VRAM 带宽和峰值显存；
2. 城市白天、夜晚、大量透明/发光面和灯光突然变化，观察线性 HDR、NRD/RR 输出和历史响应；
3. 视野大面积水面、首透明双路径、玻璃长链和 180° 快速转身；
4. 自动曝光 `-8 EV`、`0 EV` 和 `+8 EV` 下的 firefly、暗偏、漏光与残差；
5. 离线城市夜景、水面和嵌套透明的长期运行均值，确认不继承实时简化；
6. 洞穴太阳缓存初建、稳定、滚动和脏区更新，以及世界切换、资源重载、反复进入/退出离线；
7. Vulkan validation 无布局错误、提前销毁、越界、资源泄漏或跨 renderer 尺寸资源同时驻留。

### 后续候选

任何 1.0 后候选进入实现前，都需要单独说明：

1. 属于无偏方差调整、实时有偏近似，还是只改变显示测光；
2. 影响的 renderer、材质、光源、介质、历史所有者和失效 revision；
3. GPU 时间、射线数、寄存器/占用率、带宽、显存高水位和编译时间证据；
4. sample/eval/PDF、有限值、支持集、路径权重尾部或测光契约测试；
5. 曝光前线性 HDR 与最终显示的独立对照；
6. 明确的启用条件、回滚条件和不得进入离线参考路径的边界。

不能用 Oklab DRT、最终曝光或更宽松的裁剪掩盖线性 HDR 偏差。反过来，显示端放大的既有
错误也必须回到产生错误的光照、重建或大气阶段处理。
