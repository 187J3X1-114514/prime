# 着色器性能优化：未实施的方差与偏差方案

## 目的与边界

本文只记录可能改变估计方差，或引入实时可接受偏差的性能方案。本轮性能优化不实施这些方案，只接受数学等价的计算重排、公共子表达式复用、无效分支消除、生命周期缩短和契约内冗余校验移除。

参考累积必须继续保持无偏。下文标为“实时有偏”的方案即使以后采用，也只能作用于 DLSS RR、NRD 等实时产品路径，不得改变参考累积结果。

## 改变方差但可保持无偏

### 重新分配直接光采样预算

- 根据太阳、星图和面积光的估计能量动态分配样本。
- 对未被选择的光源使用正确的选择概率和 MIS PDF，可保持无偏。
- 可能减少多数场景的阴影射线，但会改变噪声的空间分布、闪烁频谱及降噪器输入。
- 需要分别回归昼夜、室内外、强小光源和透明首界面。

### 调整俄罗斯轮盘赌策略

- 可以改变起始深度和存活概率，只要存活路径除以同一概率即可保持无偏。
- 更早终止通常降低平均追踪成本，但提高长路径方差，并可能加重透明介质中的稀疏亮点。
- 需要记录平均反弹数、每像素射线数、尾部亮度分布和参考收敛速度。

### 透明首界面的采样分配

- 当前反射与透射使用两个条件分布的固定分层样本，降低了透明掠射角和多层透明的时间不稳定性。
- 改为按 Fresnel 概率随机选择单分支，在使用正确选择概率时仍可无偏并减少一条续接路径，但会显著提高方差。
- 该方向不得仅以平均帧时判断；必须同时测量闪烁、拖影和静止收敛。

### 光源分布和 MIS 启发式

- 更好的星图重要性分布、面积光树概率或 MIS 权重可降低方差，但会改变样本分布。
- 新分布必须以属性测试验证 PDF 非负、归一性、sample/eval 一致性和有限值，并以对照积分验证无偏。
- 不允许用删除低能量光源而不补偿概率的方式伪装成无偏优化。

### 时空样本序列调整

- Sobol 维度编排、分支 seed、蓝噪声置换和跨帧相位数会改变方差频谱。
- 这类修改通常不改变单样本期望，但会直接影响 NRD/RR 的历史稳定性，必须作为画质算法变更单独验收。

## 仅实时允许的有偏方案

### 辐射与吞吐量钳制

- 在降噪输入前使用亮度、色度或局部统计钳制，可抑制 firefly 并降低历史污染。
- 会压低高动态范围尾部，属于明确偏差；参考累积禁止使用。
- 若实施，阈值必须基于场景曝光无关的线性量，并提供被钳制能量的诊断视图。

### 粗糙度下限或高光瓣展宽

- 对极低粗糙度使用实时下限，可降低尖锐高光的采样方差和降噪难度。
- 会改变材质外观、反射宽度和峰值，不能归类为数值稳定性修复。
- 需要按材质类别限制，并保留镜面、玻璃和水面的显式例外或独立策略。

### 路径深度和低吞吐量强制终止

- 固定减少实时反弹数，或在吞吐量低于阈值时不做概率补偿地终止，可直接降低追踪成本。
- 会损失间接照明、深层透射和高 IOR 介质能量；参考累积禁止使用。
- 若实施，需要把缺失能量、受影响材质和最大误差作为可观测指标。

### 透明分支近似

- 只保留 Fresnel 主导分支、限制多层透明续接、复用反射/透射 guide，均可减少射线和状态。
- 这些方案会在掠射角、多层玻璃、水下和透明后强光源处形成系统误差。
- 当前固定首界面和首个透明后表面的虚拟表面策略已经解决主要稳定性问题，不应在没有专项对照时退化。

### 降噪 guide 与历史的近似

- 降低 SH1 方向分辨率、跳过低能量方向、缩短特定历史或扩大反应遮罩，通常不改变原始单帧 beauty，但会改变最终实时输出的时间估计。
- 这类变化按实时有偏方案管理，因为最终显示结果会产生系统性的模糊、滞后或能量损失。
- 必须同时检查静止收敛、相机运动、薄透明边界、反射太阳和遮挡显露。

## 后续启用条件

任何候选进入实现前，都需要单独的变更说明，至少包含：

1. 方案属于无偏方差调整还是实时有偏近似。
2. 影响的产品路径、材质、光源和介质边界。
3. GPU 时间、射线数、寄存器/占用率和带宽证据。
4. 属性测试、有限值测试及 sample/eval/PDF 契约结果。
5. 参考对照、静止收敛和运动目测结果。
6. 明确的开关、回滚条件和不可进入参考累积的边界。
