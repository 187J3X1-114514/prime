# 构建与验证

## 环境

- JDK 25；
- Vulkan SDK 1.4.350；
- SDK 中可用的 `glslangValidator` 与 `spirv-val`。

Windows PowerShell 示例：

```powershell
$env:JAVA_HOME = 'C:\Program Files\Java\jdk-25.0.2'
$env:VULKAN_SDK = 'C:\VulkanSDK\1.4.350.0'
$env:Path = "$env:JAVA_HOME\bin;$env:VULKAN_SDK\Bin;$env:Path"
.\gradlew.bat build --console=plain
```

`build` 编译 Java 和生产 Shader、运行 CPU 测试，并检查架构边界、Shader include 图、
RoboCute 参考一致性、ABI 和发行 JAR。它不执行需要 Vulkan 设备的 `shaderTest`。

## 开发运行

```powershell
.\gradlew.bat runClient
```

默认开发配置使用 Vulkan 并启用 validation。验证 OpenGL 下 Prime 不接管渲染：

```powershell
.\gradlew.bat runClient -PprimeBackend=opengl
```

不要使用 Gradle `--args` 覆盖图形后端；Loom 会将它与已有参数合并。

## 验证任务

常用门禁：

```powershell
# CPU 测试
.\gradlew.bat test --rerun-tasks --console=plain

# 完整非 GPU 构建与发行检查
.\gradlew.bat build --console=plain

# 在 Vulkan compute 设备上运行真实 GLSL 属性测试
.\gradlew.bat shaderTest --console=plain
```

主要任务：

- `test`：Java、状态机、codec、ABI 和数学性质；
- `compileShaders`：编译生产 Shader，生成普通与 SER permutation，并运行 `spirv-val`；
- `verifyShaderIncludeGraph`：检查 Shader include 图无环，报告位于
  `build/reports/prime-shaders/include-graph.txt`；
- `verifyRoboCutePort`：核对受保护 RoboCute 移植与锁定参考；
- `verifyArchitecture`：对已编译 class 运行 `jdeps` 并检查包层、反向依赖和跨层 SCC，报告位于
  `build/reports/prime-architecture/`；
- `verifyDistributionJar`：检查发行 JAR 的资源、许可、Shader 和 Windows 原生库；
- `shaderTest`：在 Vulkan 设备上执行生产 GLSL 属性测试。

Windows x86-64 测试会实际加载 NRD、FidelityFX 和 DLSS RR 桥接库并验证 ABI。其他平台
跳过 Windows native 执行，但仍编译 Java/Shader 并检查 JAR。

## Shader 调试与 replay

发布构建会剥离 SPIR-V 调试信息、执行保持语义的结构化简并再次验证。Nsight 需要源码映射时：

```powershell
.\gradlew.bat compileShaders -PprimeShaderDebug=true
```

GPU replay fixture：

```powershell
.\gradlew.bat validateReplayFixture -PprimeReplayFixture=<fixture>

.\gradlew.bat compareReplayFixtures `
  -PprimeReplayExpected=<reference> `
  -PprimeReplayActual=<actual>
```

fixture 带显式版本、SHA-256 校验和 256 MiB 读取上限。`Ctrl+Alt+F10` 的失败诊断写入
`run/prime/replay/last-failure-reference.prseq` 和 `last-failure-replay.prseq`。

## CI

GitHub Actions 在 Ubuntu 24.04、JDK 25、Vulkan SDK 1.4.350 和 Mesa Lavapipe 上运行：

```text
clean build shaderTest
```

CI 保存失败测试报告并上传构建生成的 JAR。
