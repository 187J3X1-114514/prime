# 着色器属性测试与数值诊断架构

## 目标与边界

这套测试验证实际编译并在 Vulkan 设备上执行的 GLSL 行为。Java 负责构造确定性输入、
批量提交和缩小失败见证，不复制待测公式。`shaders/robocute_bsdf_*.glsl` 仍是受保护的
固定参考移植；参考边界上的浮点奇点由 Prime 的公开适配层拒绝或钳制。

生产数学按关注点拆分：

- `numerical.glsl`：无状态数值分类与诊断阶段/字段编号。
- `transport_math.glsl`：吞吐量乘除、MIS、面积到立体角 PDF、Beer-Lambert 和轮盘赌。
- `labpbr.glsl`、`material_translation.glsl`：整数材质传输格式与物理参数翻译。
- `nrd_common.glsl`：NRD 编码、距离、辐射限幅、反调制和无效值边界。
- `bsdf.glsl`：Prime 公开 BSDF/介质栈适配；参考闭包保持在其下层。

这样可以分别审查数值稳定性、材质语义、采样契约和降噪 ABI，也允许以后只替换某一
算法模块及其属性套件。

## 执行数据流

`ShaderPropertyBatch` 先令每个 case 只写一个失败掩码。失败时，它按固定 seed 和原始输入
重放最多八类不同的 `(kind, mask)`，再请求完整 witness。常规批量不承担大输出带宽，
失败仍能定位到输入位模式和中间结果。

`ShaderComputeRunner` 是独立的 Vulkan 1.2 compute 所有者。绑定 0/1 固定为输入/输出
SSBO；额外资源通过显式绑定加入，支持 2D/3D sampled image、2D storage image、
push constants 和 XYZ workgroup。它不依赖 Minecraft 客户端或渲染器状态。

## 当前覆盖矩阵

| 关注点 | 生产入口 | 主要性质 |
|---|---|---|
| RoboCute 基础与闭包 | 固定参考移植、Prime 特化包装 | 恒等式、事件、半球、PDF、状态、分布与 LUT |
| Prime 公开 BSDF | `bsdf.glsl` | 无效样本规范化、有效载荷 finite/nonnegative、方向、η、介质栈 |
| 积分器与灯光数学 | `transport_math.glsl` | 溢出安全乘除、MIS 互补/尺度不变、衰减组合、轮盘赌重加权 |
| 材质 | `labpbr.glsl`、`material_translation.glsl` | 16-bit 轴域、字节端点、缺省值、金属 ID、Fresnel 单位区间 |
| NRD | `nrd_common.glsl` | NaN/Inf 清除、FP16 上限、颜色往返、法线、距离、反调制、合并限幅 |
| 测试执行器 | `ShaderComputeRunner` | sampled→storage→SSBO、push constants、二维 dispatch |

## 运行时诊断

原始数值诊断图的 RGBA 分别存储：

1. 累积数值标志；
2. 首次异常阶段；
3. 首次异常的 path bounce；
4. 首次异常字段类别。

“原始数值”模式按 NaN、正无穷、负无穷和有限越界着色；“原始数值（阶段）”按首次
异常阶段着色。诊断只观察会被公开适配层接受或被后续数据流消费的值，不读取参考库对
无效提案未承诺初始化的 payload。

## 回归命令

`gradlew test` 运行 CPU/ABI 测试；`gradlew shaderTest` 强制需要 Vulkan compute 并运行
全部 GPU 属性测试。CI 安装 Mesa Lavapipe 后执行两者，因此没有物理 GPU 也不能静默
跳过着色器行为回归。
